# Public source boundary

UG2 is an independent compatibility project for a local browser-based runtime on Linux and Windows. It is not affiliated with or endorsed by Electronic Arts or other game rights holders.

Public development is limited to independently implemented components and reviewed third-party code under applicable licenses. Users must provide their own lawfully obtained data. Do not publish proprietary executables, game assets, derived game code or modules, saved games, unauthorized mods, or protection bypasses. No game-specific executable selection or game-derived build is part of the public snapshot.

The current independent archive verifier checks a generic integrity manifest; it does not identify, run or transform a game executable. Integrity is not a determination of licensing or provenance. Tests use synthetic text only. The public snapshot is not a playable game release.

Do not publish game-specific runtime tooling until that review clears it. Report specific rights concerns through repository issues without posting proprietary material.
